# ☕ Coffee Shop Flutter App

## 📖 Case Study

### Overview

Coffee Shop is a modern Flutter application developed to provide users with a smooth and interactive coffee ordering experience. The app allows customers to browse coffee products, manage their cart, place orders, track order status, receive notifications, and manage their profile. An admin panel is also included for product and order management.

The project was built with a strong focus on clean UI, Firebase integration, and scalable architecture.

---

## 🎯 Problem

Traditional coffee ordering often requires customers to wait in long queues and offers limited order tracking. The objective of this project was to build a digital solution that allows customers to order coffee anytime while enabling administrators to manage products and orders efficiently.

---
